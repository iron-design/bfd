    ▼

  · 집중 시간 표시 (기본 25분)
  · "시작" 버튼
    │
    ▼
[집중 타이머 실행 중]
  · 카운트다운

    │
    ├── (포기) → [메인 위젯 — 대기 상태]
    │
    ▼

    │

  · 앱(시스템)이 이번 쉬는 안내 1가지 제시 (6종 중 무작위)

  · 사용자가 안내를 읽고 행동

  · (시안 전용) [다른 안내 보기]로 안내 교체 가능
    │
    ▼

    │
    ▼

    │
    ▼
[회복 체크인] ← 🔥 핵심
  · "지금 회복됐나요?" 질문

## 3. 화면 상태 설계

> 플로팅 위젯 기준 — 작은 창 (예: 280×180px 내외)

### 상태 1: 대기
```
┌─────────────────────┐
│  🍅 Recovery Pomo   │
│                     │
│     25:00           │
│   [▶ 시작하기]      │
│                     │
│  오늘: 🍅×2  😌×1 😵×1│  ← 오늘 요약 (아래 3-1 참고)
└─────────────────────┘
```

#### 3-1. 대기 화면 하단 — 오늘 요약

한 바퀴를 끝낼 때마다 대기 화면 아래에 짧게 표시.

| 표시 | 의미 |
|------|------|
| 🍅×N | 오늘 **한 바퀴를 끝낸 횟수** (뽀모 완료 수) |
| 😌×N | 체크인에서 **「충분히 쉬었어요」** 를 고른 횟수 |
| 😐×N | 체크인에서 **「애매해요」** 를 고른 횟수 |
| 😵×N | 체크인에서 **「못 쉬었어요」** 를 고른 횟수 |

- 예: `오늘: 🍅×2  😌×1 😵×1` → 오늘 2번 돌렸고, 그중 1번은 충분히 쉼, 1번은 못 쉼
- 0인 항목은 생략 가능 (예: 😐 없으면 표시 안 함)
- 1주차 HTML 시안: 브라우저 안에만 잠깐 유지 (새로고침 시 초기화)
- 본 앱(2주차~): Supabase 등에 저장해 유지

### 상태 2: 집중 중
```
┌─────────────────────┐
│  집중 중 🔴          │
│                     │
│     23:14           │
│  [⏸ 일시정지] [✕]  │
└─────────────────────┘
```

### 상태 3: 회복 행동 가이드 (휴식 시작)

> **역할 분리:** 위 카드 = 시스템 안내 / 아래 버튼 = 사용자 확인 + 시작 준비

```
┌─────────────────────────┐
│  쉬는 시간 🟢            │
│  ┌───────────────────┐  │
│  │ 💡 이번 쉬는 안내  │  │  ← 시스템이 제안
│  │       👁          │  │
│  │ 눈을 감고 먼 곳을 │  │
│  │ 20초간 바라보세요 │  │
│  └───────────────────┘  │
│    [다른 안내 보기]      │  ← 시안·테스트용 (선택)
│  [  확인했어요         ] │  ← 사용자 행동
│  [ 쉬는 시간 시작할     ] │
│  [   준비 됐어요       ] │
└─────────────────────────┘
```

- 직전과 **같은 안내가 연속으로 나오지 않도록** 무작위 선택 (6종, 섹션 4)
- 버튼을 눌러야만 휴식 타이머(상태 4) 시작

### 상태 4: 휴식 중
```
┌─────────────────────┐
│  휴식 중 🟢          │
│                     │
│  👁 먼 곳 바라보기  │  ← 상태 3에서 고른 안내 (짧은 이름)
│     04:30           │
│      [건너뛰기]     │
└─────────────────────┘
```

### 상태 5: 회복 체크인

│                     │

```

### 상태 6: 즉시 피드백

│                     │
│  방금 그건 회복이   │
│  아니었어요.        │
│                     │
│  [다음 집중 시작 →] │
└─────────────────────┘
```

### 상태 7: 설정 패널 (별도 창 or 확장) — 2주차 이후

```

### 상태 8: 회고 패널 (별도 창) — 2주차 이후

😵 못 쉬었어요: 1회

회복 양호 후 완주율: 100%
회복 부실 후 완주율: 50%
```

## 4. 회복 행동 가이드 콘텐츠 (초안)

> 휴식 시작(상태 3)마다 **6종 중 1개를 무작위** 제시. 직전과 동일한 안내는 가급적 피함.
> 상태 4(휴식 중)에는 해당 안내의 **짧은 이름**을 함께 표시.

| 영역 | 가이드 (상태 3 — 전체 문장) | 휴식 중 짧은 이름 (상태 4) | 근거 |
|------|---------------------------|---------------------------|------|
| 👁 눈 | 눈을 감고 20초, 또는 6미터 이상 먼 곳을 바라보세요 | 👁 먼 곳 바라보기 | 20-20-20 룰 (근거리 집중 피로 완화) |
| 🧘 인지 | 아무것도 하지 말고 멍하니 있어보세요. 폰 없이. | 🧘 멍하니 있기 | Default Mode Network 활성화 (창의성·기억 통합) |
| 🤸 목/어깨 | 천천히 목을 좌우로 기울이고, 어깨를 크게 돌려보세요 | 🤸 목·어깨 풀기 | 장시간 고정 자세 긴장 완화 |
| 🖐 손목 | 손목을 천천히 돌리고, 손가락을 쭉 펴보세요 | 🖐 손목 풀기 | 반복 입력 누적 긴장 완화 |
| 🌬 호흡 | 4초 들이쉬고, 4초 참고, 4초 내쉬세요 (박스 호흡) | 🌬 박스 호흡 | 자율신경계 안정, 코르티솔 감소 |
| 🚶 이동 | 자리에서 일어나 물 한 잔 마시고 오세요 | 🚶 물 한 잔 마시기 | 혈류 순환, 인지 재충전 |

**시안 전용:** 상태 3에서 [다른 안내 보기]로 다음 안내로 넘길 수 있음. 본 앱에서는 무작위만 유지할지 추후 결정.

## 5. 체크인 피드백 메시지 (즉시 피드백)

| 선택 | 메시지 |
|------|--------|
| 😌 충분히 쉬었어요 | "좋아요. 그 상태로 다음 블록 들어가세요." |
| 😐 애매해요 | "애매한 휴식은 반쪽짜리예요. 다음엔 폰을 멀리 해보세요." |
| 😵 못 쉬었어요 | "방금 그건 회복이 아니었어요. 다음 휴식엔 다르게 해볼까요?" |

## 6. 1주차 시안 — 쓸 화면 (확정)

한 바퀴 시안에 넣을 화면 **6개**:

1. 대기 (시작 전) — **오늘 요약** 포함
2. 집중 중
3. 쉬는 시간 안내 (시스템 가이드 + 사용자 확인 버튼)
4. 쉬는 중
5. 체크인
6. 한 줄 피드백

**이번 주 빼는 것:** 설정 패널, 하루 돌아보기 패널 (2주차 이후)

**쉬는 안내:** 6종 중 **무작위 1개** (섹션 4)

**흐름:** 대기 → 집중 → 쉬는 안내 → **[확인 버튼]** → 쉬는 중 → 체크인 → 피드백 → 대기

**HTML 겉모습 시안** (`prototype/index.html`):
- 집중 시간 테스트용 **5초 / 10초 / 25초** 선택 (본 앱에는 미포함)
- [다른 안내 보기] — 시안·데모용
