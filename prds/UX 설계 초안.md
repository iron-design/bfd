# Recovery Pomodoro — UX 설계 초안

> 버전: v0.1 | 작성일: 2026-07-10
> 기반: 회복형 집중 타이머 PRD v1.2

---

## 1. 기능 목록

### Must-have

| 기능 | 설명 | 화면/컴포넌트 |
|------|------|--------------|
| 집중 타이머 | 25분(기본) 카운트다운 | 메인 위젯 |
| 휴식 타이머 | 5분(기본) 카운트다운 | 메인 위젯 |
| 인터벌 설정 | 집중/휴식 시간 직접 설정 | 설정 패널 |
| 타이머 알림 | 집중/휴식 종료 시 macOS 알림 | 시스템 알림 |
| 회복 행동 가이드 | 휴식 시작 시 신체+인지 회복 행동 제시 (인지심리학 기반) | 가이드 뷰 |
| 회복 체크인 | 휴식 종료 후 원탭 응답 (3단계) | 체크인 모달 |
| 즉시 피드백 | 체크인 결과 한 줄 되비추기 | 피드백 뷰 |
| 사이클 연결 | 체크인 완료 → 다음 집중 블록 시작 | 메인 위젯 |

### Should-have

| 기능 | 설명 | 화면/컴포넌트 |
|------|------|--------------|
| 세션 누적 | 오늘 완료한 뽀모 횟수 + 체크인 기록 | 메인 위젯 하단 |
| 블록 간 비교 | 회복 양호 vs 부실 후 집중 완주율 | 회고 뷰 |
| 하루 회고 | 오늘 회복 패턴 요약 | 회고 패널 |

## 2. 유저 플로우

```
[앱 실행]
    │
    ▼
[메인 위젯 — 대기 상태]
  · 집중 시간 표시 (기본 25분)
  · "시작" 버튼
    │
    ▼
[집중 타이머 실행 중]
  · 카운트다운
  · 일시정지 / 포기 버튼
    │
    ├── (포기) → [메인 위젯 — 대기 상태]
    │
    ▼
[집중 종료 알림]
  · macOS 알림 발송
    │
    ▼
[회복 행동 가이드] ← 💡 새 단계
  · 신체/인지 회복 행동 1가지 제시
    예) "지금 눈을 감고 20초간 먼 곳을 바라보세요"
    예) "어깨를 크게 돌리고, 목을 좌우로 천천히 기울여보세요"
  · 휴식 타이머 자동 시작
    │
    ▼
[휴식 타이머 실행 중]
  · 카운트다운 + 가이드 메시지 유지
  · 건너뛰기 버튼
    │
    ▼
[휴식 종료 알림]
  · macOS 알림 발송
    │
    ▼
[회복 체크인] ← 🔥 핵심
  · "지금 회복됐나요?" 질문
  · 3가지 선택지 (원탭)
    ├── 😌 충분히 쉬었어요
    ├── 😐 애매해요
    └── 😵 못 쉬었어요 (폰 봤거나, 불안했거나)
    │
    ▼
[즉시 피드백]
  · 선택에 따른 한 줄 메시지 표시
    예) "방금 그건 회복이 아니었어요. 다음 휴식엔 다르게 해볼까요?"
  · "다음 집중 시작" 버튼
    │
    ▼
[메인 위젯 — 대기 상태]
  · 오늘 완료 뽀모 수 + 회복 요약 업데이트
  · 다음 사이클 준비
```

## 3. 화면 상태 설계

> 플로팅 위젯 기준 — 작은 창 (예: 280×180px 내외)

### 상태 1: 대기
```
┌─────────────────────┐
│  🍅 Recovery Pomo   │
│                     │
│     25:00           │
│   [▶ 시작하기]      │
│                     │
│  오늘: 🍅×2  😌×1 😵×1│
└─────────────────────┘
```

### 상태 2: 집중 중
```
┌─────────────────────┐
│  집중 중 🔴          │
│                     │
│     23:14           │
│  [⏸ 일시정지] [✕]  │
└─────────────────────┘
```

### 상태 3: 회복 행동 가이드 (휴식 시작)
```
┌─────────────────────┐
│  휴식 시작 🟢        │
│                     │
│  👁 눈을 감고 먼 곳을│
│  20초간 바라보세요  │
│                     │
│     05:00 ▶         │
└─────────────────────┘
```

### 상태 4: 휴식 중
```
┌─────────────────────┐
│  휴식 중 🟢          │
│                     │
│  👁 먼 곳 바라보기  │
│     04:30           │
│      [건너뛰기]     │
└─────────────────────┘
```

### 상태 5: 회복 체크인
```
┌─────────────────────┐
│  지금 회복됐나요?   │
│                     │
│  😌 충분히 쉬었어요 │
│  😐 애매해요        │
│  😵 못 쉬었어요     │
└─────────────────────┘
```

### 상태 6: 즉시 피드백
```
┌─────────────────────┐
│  😵 못 쉬었군요.    │
│                     │
│  방금 그건 회복이   │
│  아니었어요.        │
│                     │
│  [다음 집중 시작 →] │
└─────────────────────┘
```

### 상태 6: 설정 패널 (별도 창 or 확장)
```
집중 시간: [25] 분
휴식 시간: [5] 분
알림 소리: [ON/OFF]
```

### 상태 7: 회고 패널 (별도 창)
```
오늘 요약
───────────────────
🍅 완료한 뽀모: 4개
😌 충분히 쉬었어요: 2회
😐 애매해요: 1회
😵 못 쉬었어요: 1회

회복 양호 후 완주율: 100%
회복 부실 후 완주율: 50%
```

## 4. 회복 행동 가이드 콘텐츠 (초안)

> 인지심리학 + 신체 피로 기반. 휴식 시작 시 1개 랜덤 또는 순환 제시.

| 영역 | 가이드 | 근거 |
|------|--------|------|
| 👁 눈 | 눈을 감고 20초, 또는 6미터 이상 먼 곳을 바라보세요 | 20-20-20 룰 (근거리 집중 피로 완화) |
| 🧘 인지 | 아무것도 하지 말고 멍하니 있어보세요. 폰 없이. | Default Mode Network 활성화 (창의성·기억 통합) |
| 🤸 목/어깨 | 천천히 목을 좌우로 기울이고, 어깨를 크게 돌려보세요 | 장시간 고정 자세 긴장 완화 |
| 🖐 손목 | 손목을 천천히 돌리고, 손가락을 쭉 펴보세요 | 반복 입력 누적 긴장 완화 |
| 🌬 호흡 | 4초 들이쉬고, 4초 참고, 4초 내쉬세요 (박스 호흡) | 자율신경계 안정, 코르티솔 감소 |
| 🚶 이동 | 자리에서 일어나 물 한 잔 마시고 오세요 | 혈류 순환, 인지 재충전 |

## 5. 체크인 피드백 메시지 (즉시 피드백)

| 선택 | 메시지 |
|------|--------|
| 😌 충분히 쉬었어요 | "좋아요. 그 상태로 다음 블록 들어가세요." |
| 😐 애매해요 | "애매한 휴식은 반쪽짜리예요. 다음엔 폰을 멀리 해보세요." |
| 😵 못 쉬었어요 | "방금 그건 회복이 아니었어요. 다음 휴식엔 다르게 해볼까요?" |

## 6. 열린 결정 사항

- [ ] 체크인 선택지 3개 vs 2개 (심플하게 "됐다 / 안 됐다"로 줄일지)
- [ ] 피드백 메시지 톤 — 따뜻하게 vs 데이터 중심으로
- [ ] 회고 패널 진입 방법 — 위젯 클릭? 별도 버튼?
- [ ] 위젯 기본 위치 — 우하단 고정? 사용자 이동 가능?
